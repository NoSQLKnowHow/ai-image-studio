# (see requirements-container.txt). Installed by a Dockerfile step of their own, so that if they cannot be installed (no wheel for a
# new Python, say) the build prints a note and goes on, as it does when spandrel cannot be imported, and the Vector tab says why it is not
# available (`capabilities.vector`) instead of the whole image failing to build.

# Python 3.12): vtracer 0.6.15 (MIT) as manylinux2014 wheels, shapely 2.2.0 (BSD-3-Clause) as manylinux_2_28 wheels. shapely needs numpy
# 1.26 or later, which NVIDIA's pin satisfies. NOT confirmed: that they import and run inside NVIDIA's image on the Spark. The image build
# prints a line for each (docker/check_image.py: "Vector: ...") that says so, or says why not.
